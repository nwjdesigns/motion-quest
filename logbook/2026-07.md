## 2026-07-14 — Grid rig build session 1: responsive typographic grid in Cavalry

**Tool**: Cavalry 2.x + Claude Code (pair build)  ·  **Tags**: poster-machine, grid-system, cavalry, duplicator, js-utility

**What happened:** First hands-on Cavalry build session for Poster Machine. Noah building in Cavalry, Claude guiding from docs research. Built a fully responsive typographic grid system from scratch: columns, rows, text distribution across cells.

**Architecture (proven pattern):**
- JavaScript Utility on Rectangle Shape Width: `(1080 - 2*margin - (columns-1)*gutter) / columns`
- Plain Math node adds gutter to column width for Duplicator step distance
- Two axis systems: Columns group (JS Utility [Size.W] + Math + Duplicator horizontal) and Rows group (JS Utility 2 [Size.H] + Math 2 + Duplicator 2 vertical)
- Text via String Array (A, B, C, D...) auto-indexed by Duplicator 3 (Point distribution)
- Per-duplicate positioning: Index Context node wired to JS Utility inputs, position formulas use `index % columns` and `Math.floor(index / columns)`
- Text Box Size W driven by span formula: `span * columnWidth + (span-1) * gutter`
- Key discovery: **Duplicator ignores input shape transforms**; must use Shape Position attribute on the Duplicator itself

**Hard-won lessons:**
- Origin mismatch: Duplicator centres distribution, position formulas need `-(1080/2)` / `(1920/2)` offsets
- Y axis inverted in Cavalry (positive = up)
- ctx.index works in JS Utility but Index Context node is more reliable for wiring
- Text Box Size W IS connectable (confirmed; no scale hack needed for grid-snapping)

**Scope expanded beyond spec:** Original L1 was columns-only with 5 controls. Noah pushed to include rows and text in the same session ("won't be much of a start if all we can do is columns"). L1 and L2 merged in practice.

**Parked for next session:** Stagger entrance animation (between words and/or between letters within words). Controls not yet exposed to Control Centre. Ink/Paper colours, font (Space Grotesk). Asset Array for images (same pattern as String Array). Figma-style "Count" control label.

**Backlog addition:** Cavalry Grid Rig Generator script (auto-generate the full grid setup via `api` module). Building manually exposed how tedious node-by-node wiring is.

**Cavalry file:** saved at `~/Desktop/2026/EES/DAILY/PRODUCTION/07_JULY/CAV/july_main_build.cv` (visible in title bar). Four comps: 01 columns, 02 rows and text, 03 autolayout, 04 duplicates.

**Technique notes (verified against Cavalry docs, now at cavalry.studio/docs):**
- Text Shape is a sub-mesh: behaviour + Stagger = per-glyph animation (the canonical pattern)
- Sub Mesh Deformer for direct per-glyph transforms; Recursion toggles characters vs words
- Text-on-path is native (spline into Text Shape, alignment anchors to path start/centre/end)
- Duplicator echo trick: Text Shape into Duplicator, second Stagger on Shape Time Offset + Position, Colour Array on fills
- Style switching: Comparison / If Else utilities driving group Visible attributes
- Web player renders only flat Control Centre attributes: slider, scrubber, menu (enum only), toggle, colour, text
- Font licensing: sellable `.cv` files need an OFL typeface shipped with them (Space Grotesk recommended); Helvetica Neue can't ship
